Enrôlement + Recherche multi-photos (définit une CIBLE)
Journal Voir les caméras
Enrôlement
Ajoute une personne en base (utile pour le mode DB quand le visage est visible).
Conseil : 3 à 10 photos, angles/lumières variés.
Recherche multi-photos → CIBLE
Charge plusieurs photos pour définir une CIBLE plus stable. À visualiser sur /cameras.
Après “Définir la cible”, ouvre /cameras pour voir les modes TARGET/DB/UNK en direct.
Personnes enrôlées
Supprimer une personne efface son empreinte et retire son nom du journal.
